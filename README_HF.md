# FireLink - two satellites, one clear answer

NASA FIRMS VIIRS + MODIS fire detections reconciled into a single map, with a burned-day calendar,
multi-year history comparison, burned-area estimates and email alerts.

Source code and documentation: https://github.com/YoussefYT12/Firelink
